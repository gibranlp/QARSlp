# QARSlp is now SpectrumOS

> [!WARNING]
> **QARSlp is deprecated in its entirety. All development has moved to [SpectrumOS](https://github.com/gibranlp/SpectrumOS).**
> This repository is retained for historical reference and is no longer maintained. Its scripts, configurations, themes, and installation instructions are obsolete.

## Continue with SpectrumOS

QARSlp began as a Qtile + Arch ricing setup. That work has evolved into **SpectrumOS**, a complete Arch Linux distribution with a Hyprland desktop and a Quickshell interface.

SpectrumOS carries the wallpaper-driven desktop idea forward with coordinated colors across the shell and supported applications, integrated widgets, multi-monitor controls, and tools for everyday work and gaming. It also includes Stash, Questline, and UKVM as part of the desktop experience.

**SpectrumOS replaces this project.** All new features, fixes, documentation, and installation guidance belong there. Use the SpectrumOS documentation for current setup instructions, and direct issues and contributions to its repository.
